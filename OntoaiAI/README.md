Прототип картографического компонента ФГИС ЕЦП НСПД взаимодействующего с большой языковой моделью (LLM).
Особенностью реализации прототипа является использование классификаторов для разметки / тэгирования / кодирования данных и документов в машиночитаемых форматах - онтологии и json (ttl).
Данный подход позволяет а) передавать данные в LLM в более формализованном и понятном для ИИ виде; б) открывает возможность к реализации мультиагентных систем с использованием пространственных данных; в) реализовывать сложную бизнес-логику "зашитую" в документах "силами" ИИ и при необходимости дополнительных инструментов (MCP Tools)
